UI / UX

Two surfaces, one DiffResult

The GH components produce the result and check rules against it. The Rhino panel is where people look at it. Both use the same colors and the same evidence badges.

A · Grasshopper definition (v0)

  • Snapshot is cached per file version, so moving a slider downstream doesn't re-read the 3dm.
  • Model Diff outputs plain GH geometry and attributes, so any downstream component works with them.
  • Assert Unchanged turns the diff into a QA gate. It can run headless on Rhino.Compute or in CI.
  • Open Review sends the result to the Rhino panel below for browsing.

UX choices worth keeping

Review is a to-do list
Rows can be ticked off, and that state is saved with the DiffResult. A team can sign off on "v12 → v13" and anyone can see what was checked.
Confidence is always visible
Each pair shows a GUID, hash or fuzzy 0.91 badge. Fuzzy pairs get an Unlink button, because a wrong pairing is worse than an added + removed pair.
Causes first, objects second
Table events sit at the top and expand to show the objects they affect. One layer rename should never turn into 212 rows.
