Follow-up · Geometry changes

Yes: rebuilds, CV/vertex edits, topology. Each gets its own label.

"Geometry changed" by itself isn't useful. Each changed pair goes through a short ladder of questions, so a rebuild that kept the shape is reported differently from a dragged control point or a solid that became open.

no ↓
5Same topology?faces · edges · naked edges · closed / solid
yes →
Reshapeddeviation: max, mean, and where. Polylines use a vertex sequence diff
no →
Topology changede.g. ⚠ solid became open, or a face was split or merged
Only step 1 runs on every pair, and it's a hash compare. Steps 2–5 run only on pairs whose hash differs, usually a few percent of the model, so the expensive deviation sampling stays cheap.
