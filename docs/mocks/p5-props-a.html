Show what didn't change as clearly as what did

For confidence, the output you want is a sentence like "outside Facade, only 28 objects changed, in 3 batches", not 300 rows. That needs three levels of detail: matrix → change sets → one object.

4 · Change setgroup by identical change
layer

one row, not 23

Store where each value comes from (ByLayer, ByObject or ByParent). Then you know whether the object changed or only its layer did. Accidents usually happen in batches, e.g. select-all followed by a layer change, so grouping identical changes makes them easy to spot.
