Layer changes specifically: a flow view

Most objects stay where they were, shown as faint bands. Objects that move layers stand out, and an accidental move into Default is obvious at a glance.

The other 5 layers keep all their objects and are collapsed here. In the plugin, clicking a band would select those objects in Rhino.

Status

Accidental-change detectors (each flags a change set)

  • ⚠Outside declared scopeany change on layers you didn't say you'd touch
  • ⚠Moved to Default / current layera classic result of having the wrong layer active
  • ⚠Tiny nudgesmoves smaller than ~10× tolerance, e.g. a gumball or arrow-key slip
  • ⚠ByLayer → overridecolor, material or linetype set directly on the object
  • ⚠Duplicatesan added object with the same geometry hash as an existing one
  • ⚠Edits on locked or hidden layersthose layers were locked or hidden in A, so how did anything change there?
  • ⚠Lone deletionsa few objects removed from a layer where nothing else changed
  • ⚠Mass identical changethe same change on many objects across unrelated layers (select-all)
