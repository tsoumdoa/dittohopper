How do you track layer renames, layer moves and the like?

Treat layers as their own table to diff, with their own IDs. The same goes for blocks, materials, linetypes and groups. Diff those tables first to build an A→B mapping, then compare every object through that mapping.

Rules behind it

A rename is not an object change
Objects reference a layer by ID, not by name. Compare map(A.layer) with B.layer. A renamed or re-parented layer then produces zero object rows.
A ByLayer change belongs to the layer
If an object's color, material or linetype is set ByLayer, the object itself didn't change. Report it once on the layer, and offer an "effective appearance" view for people who care what it looks like.
Blocks work the same way
Editing a definition gives one row: "Window-A changed · 48 instances". An instance only gets its own row when its own transform or attributes change.
No shared IDs? Infer them
For rebuilt files, match by full path, then by name, then by where the matched objects went. If 95% of A::Slabs now sits on B::Floor, that's a rename. Mark it as inferred.
